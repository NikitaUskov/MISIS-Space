# Обновление: самостоятельная регистрация

Этот архив предназначен для уже работающего календаря. В docs находятся только четыре обновлённых файла: index.html, app.js, api.js и styles.css.

## 1. Обновите сайт

1. Распакуйте архив.
2. На GitHub откройте существующую папку docs вашего репозитория.
3. Выберите Add file → Upload files. Перетащите внутрь четыре файла ИЗ папки docs архива (не саму папку, чтобы не получить docs/docs).
4. Нажмите Commit changes и дождитесь успешной публикации GitHub Pages.
5. Откройте сайт и обновите страницу с Ctrl+F5. На телефоне при старой версии закройте вкладку и откройте сайт снова.

config.js в архив не включён: ваш адрес Supabase и публичный ключ остаются в уже загруженном файле. Базу данных и schema.sql повторно запускать не нужно.

## 2. Разрешите регистрацию

В Supabase: Authentication → Sign In / Providers.
- Allow new users to sign up — включить.
- Allow anonymous sign-ins — оставить выключенным.
- Открыть Email: вход по почте оставить включённым, Confirm email выключить.
- Сохранить настройки.

Это вариант без писем: почта служит логином, её владелец не проверяется. Любой посетитель сайта сможет зарегистрироваться. Аккаунты вручную создавать не нужно.

## 3. Проверьте

1. На сайте нажмите Войти → Регистрация.
2. Введите новую почту, пароль от 8 символов и повторите его. Нажмите Зарегистрироваться.
3. Общий календарь должен открыться сразу. Создайте тестовую бронь.
4. На телефоне войдите с той же почтой и паролем: бронь должна появиться.
5. С другим аккаунтом эта бронь видна, но её нельзя изменить или удалить.

На телефоне нижняя синяя кнопка «Новая бронь» убрана. Белая «Добавить бронирование» доступна во всех четырёх режимах. На компьютере создание брони доступно через верхнюю кнопку.

## Проверки

50 автоматических проверок прошли: 26 хранилища, 12 формы/календаря, 12 регистрации. Ответы Supabase в тестах имитируются. Проверку с вашим реальным проектом нужно выполнить после загрузки и изменения настроек. Визуальная проверка браузером в текущей среде недоступна.

Восстановление пароля через сайт не добавлялось; при забытом пароле пока нужен организатор.
